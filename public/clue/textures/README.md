# Clue floor texture

`worn-concrete.jpg` is the original, unmodified 1K diffuse JPEG from
[Concrete Floor Worn 001](https://polyhaven.com/a/concrete_floor_worn_001)
by Poly Haven.

- Photography: Dimitrios Savva
- Processing: Rico Cilliers
- License: [CC0](https://polyhaven.com/license), including commercial use
- Download: https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/concrete_floor_worn_001/concrete_floor_worn_001_diff_1k.jpg

The download was checked against the MD5 supplied by the official Poly Haven
files API. The shared Clue stylesheet repeats this photograph across the
corridors and room floors; a light CSS overlay in rooms keeps the graphics
readable.
